
### UI Components

1. **Master Volume Slider** (0-100%) — Controls overall game volume. Affects all sounds proportionally.
2. **SFX Volume Slider** (0-100%) — Controls one-shot sound effects (catch, dive, anomaly, etc.)
3. **Music Volume Slider** (0-100%) — Controls music track volume
4. **Ambient Volume Slider** (0-100%) — Controls ambient zone track volume
5. **Mute All Toggle** — Quick mute/unmute button
6. **Sound Test Input** — Debug input to play any SFX by name (see Section 6)
7. **Save Button** — Persists settings to player profile

## Section 7: Audio Persistence

### Data Structure (saved to player profile)

```json
{
  "AudioSettings": {
    "MasterVolume": 0.8,
    "SFXVolume": 0.9,
    "MusicVolume": 0.5,
    "AmbientVolume": 0.75,
    "Muted": false
  }
}
```

### Implementation Notes
- Load settings in `AudioController:KnitStart()`
- Apply volume multipliers: `effectiveVolume = baseVolume * (MasterVolume/100) * (categoryVolume/100)`
- Save on each slider change (debounced 500ms) AND on Save button click
- Load from ProfileService or DataStore on join
- Default to full volume (1.0) on first join
