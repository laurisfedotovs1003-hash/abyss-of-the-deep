# Assets

This directory contains reference notes for game assets.

## Asset Pipeline

1. **3D Models** — Created in Blender, exported as `.fbx`, uploaded to Roblox
2. **Textures** — Created in Photoshop/Aseprite, uploaded to Roblox
3. **Audio** — Created in Audacity/FMOD, uploaded to Roblox
4. **Animation** — Created in Roblox Studio Animation Editor

## Required Assets by System

### Environment
- [ ] Ocean surface skybox (day/night cycle)
- [ ] Underwater fog volumes per depth layer
- [ ] Bioluminescent particle effects
- [ ] Seabed terrain (sandy, rocky, volcanic per layer)
- [ ] Shipwreck / cave / vent decorations

### Creatures
- [ ] ~25 fish/creature models (5 per depth layer)
- [ ] Creature animations (idle swim, flee, attack)
- [ ] Shiny variant textures (recolor)
- [ ] Catch effect VFX
